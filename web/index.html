claimable

Unassigned is not the same as free. Paste an issue and see whether anyone has beaten you to it, before you spend a weekend on it.

Checking more than a few issues an hour?

Without a token GitHub allows 60 requests an hour from your address, and one issue takes about eight. A token raises that to 5,000. A fine-grained token with no permissions at all is enough, since everything read here is public.

It goes only to api.github.com, straight from this page, and is kept for this tab. Nothing here has a server.

The same seven checks as the command-line tool, running in your browser against GitHub's public API: repo alive, existing PR, blocked or umbrella, claimants, prerequisites, environment, claim protocol. Every finding links to where you can check it yourself.

In a terminal it is npx claimable owner/repo#123, and it can also scan a whole repository or a search. Source, evaluation and issues on GitHub.
